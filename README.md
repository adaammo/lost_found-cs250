# Lost&Found @ SDSU
Lost&Found @ SDSU is a full-stack web applicaton meant to help the students of SDSU communicate with each other over lost items. Users can create items by dropping a pin on the map, communicate with others over their lost items, and mark items as found when resolved. 
## Techstack (as of 9/17/26)
### Frontend:
NextJS - (Typescript, React, TailwindCSS) \
### Backend:
FastAPI(Python), Supabase/PostgresSQL (Database) \
 ### Getting started on /src
 - npm install \ npm i : run this to download all dependencies/libraries needed for this project **very important to do if you just cloned the repo**
 - npm run dev : start the development environment for this project
 - npm run build: build the production environment for this project 
 **ALWAYS RUN NPM RUN BUILD AND NPM START BEFORE COMMITTING.**
 - npm start: Start the production environment built from the last npm run build
